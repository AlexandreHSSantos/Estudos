COMANDOS

Fetch procura alterações no repositório pull traz as alterações para a máquina push envia as alterações para o repositório U significa que o arquivo foi criado, mas a alteração ainda não foi lançada no repositório M significa que foi feita uma alteração no arquivo mas ele ainda não foi feito push

COMANDOS

  • Fetch procura alterações no repositório
  • pull traz as alterações para a máquina
  • push envia as alterações para o repositório
  • U significa que o arquivo foi criado, mas a alteração ainda não foi lançada no repositório
  • M significa que foi feita uma alteração no arquivo mas ele ainda não foi feito push
